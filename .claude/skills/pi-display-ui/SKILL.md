# Pi Display UI（800x480 タッチ画面の UI 作業）

シス研Pay は部室の **Raspberry Pi 5 + 5インチ DSI タッチモニター（800x480・横向き）** にキオスク表示して使う。PC のブラウザで良く見えても、実機では文字が小さすぎたり、ボタンが画面外に出たりする。UI を触るときは、実装の前後でこのスキルの手順を通す。

## 前提（画面サイズの仕組み）

`sysken-pay-front/src/index.css` の冒頭で決めている。**ここを読んでから作業する**。

- `--screen-width: 800px` / `--screen-height: 480px` / `--ui-scale: 0.5`
- スタイルはすべて **rem 基準で、1600x960 のデザインを 0.5 倍** にして表示している（1rem = 8px）
- `#root` が 800x480 の「画面の枠」。PC の開発時は枠が中央に出て、外側はグレー
- `#root` に `contain: layout paint` があるので、`position: fixed` の要素は**ウィンドウではなく枠**を基準に配置される

## ルール

1. **長さは rem で書く**。`px` で書くと `--ui-scale` で縮まず、実機だけ大きさがずれる（例外: `1px` の罫線、`9999px` の角丸）
2. **`100vh` / `100vw` を使わない**。ページの高さは `height: 100%`（枠の高さ）。vh は PC ではウィンドウ全体の高さになり、枠からはみ出す
3. **スクロール前提にしない**。キオスクではスクロールバーが無く、`overflow: hidden` で切れる。1画面に収まらないなら、項目を減らす・ページを分ける・リスト部分だけ `overflow-y: auto` にする
4. **タッチしやすい大きさにする**。押せる要素は実機で高さ 44px 以上（= `5.5rem` 以上）、隣のボタンとの間隔もとる
5. **文字は小さくしすぎない**。本文は `1.75rem`（実機 14px）以上、注意書きでも `1.5rem`（12px）以上を目安にする
6. **hover に頼らない**。タッチ画面に hover は無い。押した反応は `:active` で出す
7. 色はデザイントークン（`src/styles/scss/_design-primitive.scss` の `$blue-40` 等）を使い、色の直書きを増やさない

## 手順

### Step 1: 触る画面を確認する

対象ページ（`src/pages/**`）と、使っているコンポーネント（`src/components/**`）、それぞれの `*.module.scss` を読む。似た画面がすでにあれば、余白・ボタン配置（左下に「戻る」、右下に「次へ」等）をそろえる。

### Step 2: 実装する

上のルールに沿って書く。新しいページなら、既存ページの `.container { display: flex; height: 100%; flex-direction: column; overflow: hidden; }` の形を踏襲する。

### Step 3: 800x480 で見た目を確認する

確認は必須。「たぶん収まる」で終わらせない。

1. `cd sysken-pay-front && pnpm dev`
2. ブラウザで開くと 800x480 の枠が出るので、その中に収まっているか見る
   - Claude が自分で確認する場合は、Playwright（devDependencies に入っている）で `viewport: { width: 800, height: 480 }` のスクリーンショットを撮り、Read で画像を見る
3. 見る点
   - 画面の下・右で切れている要素がないか（特に固定配置の「戻る」「次へ」ボタンと、中身の重なり）
   - 文字が折り返して崩れていないか
   - モーダル（`CompletionModal`、ヘッダーの確認ダイアログ）が枠の中に出るか
4. Storybook（`pnpm storybook`）でもコンポーネント単体を確認できる。`.storybook/preview.ts` で `index.css` を読み込んでいるので、文字の大きさは実機と同じ

### Step 4: 報告する

変更した画面と、800x480 で確認したこと（スクリーンショットがあれば添える）を伝える。**実機（ラズパイ）ではまだ見ていない**場合はそう書き、実機で見てほしい点（タッチのしやすさ、文字の読みやすさ）を挙げる。

## モニターを替えるとき

`index.css` の `--screen-width` / `--screen-height` / `--ui-scale` を変える。`--ui-scale` は「新しい画面の幅 ÷ 1600」が目安（例: 1024x600 なら 0.64）。縦横比が 5:3 から離れる場合は、全ページを Step 3 の手順で見直す。
